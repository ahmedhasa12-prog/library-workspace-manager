## 🚀 How to Get Your Installer (3 Simple Steps)

### Step 1: Prepare Windows Machine
- Install **Node.js** from https://nodejs.org/ (just download and click "Next")

### Step 2: Get the Code
- Copy this entire folder structure to your Windows computer

### Step 3: Build & Install
1. Double-click `build-windows.bat`
2. Wait for automatic build to complete (5-10 minutes)
3. Find your installer: `dist-electron\Library Workspace Manager Setup x64.exe`
4. Double-click the .exe to install on any Windows computer
